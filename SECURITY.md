# Security Policy

Vyu is a Windows desktop application that processes local media files. Please do
not post suspected vulnerabilities, exploit details, or sensitive reproduction
files in public GitHub issues or through the in-app feedback UI.

Use GitHub's **Report a vulnerability** option in the repository's Security tab
to contact the maintainer privately. If that option is unavailable, open an
issue asking for a private reporting channel; do not include technical details
or attach files there.

Vyu is in development, and there is no formal response-time guarantee. Reports
against the latest development version are most useful.
